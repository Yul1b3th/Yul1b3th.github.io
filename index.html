Sobre mí

Sobre mí

Desde 2016 trabajo en desarrollo web, evolucionando desde maquetación y frontend hasta aplicaciones modernas con Angular, TypeScript y arquitecturas escalables. Trabajo con Angular 16+, desarrollando componentes reutilizables, formularios dinámicos, gestión de estado con Angular Signals, integración de APIs REST, pruebas unitarias y mejoras de UX/UI en aplicaciones enterprise.

Tengo experiencia en mapeo de DTOs, asincronía con RxJS, testing y colaboración con Git Flow y Azure DevOps. Además, continúo profundizando en Angular moderno, arquitectura frontend y buenas prácticas de desarrollo.

También sigo implementando mejoras y nuevas funcionalidades en mis proyectos personales para continuar evolucionando técnicamente:

• EZHub DS → Design System con Angular. Disponible en EZHub DS.

• EZHub → aplicación de búsqueda de habitaciones con geolocalización (Angular + NestJS + MySQL). Disponible en EZHub.

Actualmente busco nuevas oportunidades como Frontend Developer Angular, donde pueda aportar experiencia en desarrollo SPA, calidad de código y aprendizaje continuo.

Proyectos

Proyectos

EZHub

Aplicación en desarrollo para la búsqueda de habitaciones por geolocalización, diseñada como proyecto final de mi bootcamp de Angular en IT Academy. La aplicación permite interactuar con el backend para gestionar usuarios, propiedades y habitaciones, e incluye autenticación de usuarios con JWT y encriptación de contraseñas. Desarrollada con Angular, Nest, MySQL, Mapbox y TailwindCSS.

ITA Challenges

Aplicación en desarrollo de la IT Academy que permite a los estudiantes participar en retos de programación y hacer seguimiento de su progreso. En 2024, colaboré activamente implementando funcionalidades interactivas, realizando pruebas unitarias con Jest y gestionando tareas en GitHub.

Repositorios: Frontend | Backend

EduMap

Aplicación que permite a los usuarios visualizar y analizar datos relacionados con el acceso y la equidad en la educación a través de mapas interactivos. Los datos, obtenidos de OpenData Barcelona, permiten explorar indicadores por distrito, como ingresos familiares y distribución de centros educativos. Este proyecto fue parte de una hackatón en IT Academy, realizada el 22 de octubre de 2024, por un equipo compuesto por profesionales de las disciplinas de Data Analyst, Backend y Frontend.

Repositorios: Frontend | Backend

Demo

TryTime

Aplicación web que genera actividades aleatorias, diseñada para la hackatón de IT Academy en 2024. Desarrollada con Angular y Server-Side Rendering (SSR) para mejorar el rendimiento y SEO. TryTime permite a los usuarios obtener actividades aleatorias de la Bored API, con opciones de filtrado por tipo de actividad. Incluye manejo de errores de red, optimización de CORS con proxy y un diseño responsivo adaptado a dispositivos móviles y escritorio.
